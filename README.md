# Лабораторная работа №1: Алгоритмы и структуры данных (АиСД)

## 📌 Описание проекта
Данный репозиторий содержит реализацию базовых структур данных на языке **C++**, а  **алгоритма сортировочной станции Эдсгера Дейкстры**.

## 🛠 Реализованные структуры данных

В проекте не используются стандартные контейнеры STL (за исключением базовых типов). Все структуры написаны с нуля:

1. **Динамический массив (`DynamicArray`)** — аналог `std::vector` с автоматическим перевыделением памяти при расширении.
2. **Двусвязный список (`DoublyLinkedList`)** — структура данных, состоящая из узлов, содержащих ссылки на следующий и предыдущий элементы.
3. **Стек (`Stack`)** — структура, работающая по принципу LIFO (Last In, First Out), реализованная на базе разработанного двусвязного списка.

## 🧮 Основной алгоритм: Сортировочная станция
**Алгоритм сортировочной станции (Shunting-yard algorithm)** используется для преобразования математических выражений из привычной *инфиксной нотации* (например, `3 + 4 * 2`) в *обратную польскую нотацию (ОПН)* или *постфиксную нотацию* (`3 4 2 * +`).

**Особенности реализации:**
* Поддержка базовых арифметических операций (`+`, `-`, `*`, `/`).
* Корректная обработка приоритетов операций и круглых скобок `()`.
* Поддержка функций (`sin`, `cos`).
* Использование собственного `Stack` для хранения операторов в процессе парсинга.
* Вычисление итогового значения выражения на основе полученной постфиксной записи.

## 🚀 Инструкция по сборке и запуску

### Требования
* Компилятор с поддержкой стандарта **C++17** или выше (GCC, Clang, MSVC).
* Система сборки **CMake** (опционально, если используется).

### Сборка через консоль
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd Laba_1_AISD
   ```
2. Скомпилируйте проект (пример для g++):
   ```bash
   g++ -std=c++17 main.cpp -o main
   ```
3. Запустите исполняемый файл:
   ```bash
   ./main.cpp
   ```
